# Operion — Vercel

Розпакуйте архів і завантажте вміст папки operion-vercel у GitHub-репозиторій. Імпортуйте репозиторій у Vercel. Framework: Other. Build Command: npm run build. Output Directory: public. Node.js: 22.x. Конфігурація вже є у vercel.json.

Альтернатива через термінал у папці проєкту:

```sh
npm test
npm run build
npx vercel --prod
```

Для форми додайте у Vercel Settings → Environment Variables:
- RESEND_API_KEY — ключ вашого облікового запису Resend.
- OPERION_MAIL_FROM — адреса на домені, підтвердженому в Resend, без імені відправника.
- OPERION_SITE_URL — необов’язково, основна адреса сайту з https://.

Після додавання змінних виконайте Redeploy. Адресат зафіксований: fusioeng@gmail.com. Без поштових налаштувань сервер чесно повертає помилку. Реальне надсилання з вашим ключем не перевірялося; тести використовують імітацію провайдера. PHP для цього пакета не потрібен. Ліміт заявок у коді діє на один екземпляр функції; загальний ліміт можна налаштувати у Vercel Firewall.

## Мова

Перемикач прибрано. На завантаженні викликається браузерна геолокація. Україна — українська, Італія — італійська, інші країни — англійська. Відмова, блокування, помилка чи тайм-аут — українська. Браузер сам вирішує, чи показувати запит повторно з урахуванням збережених дозволів. Потрібен HTTPS (Vercel надає його).

Координати обробляються локально, не надсилаються геокодеру та не записуються. Карта кордонів завантажується після отримання координат. Атрибуція та ліцензії — dist/assets/geo-attribution.txt. Поблизу кордонів результат залежить від точності геолокації й карти.

У пакеті є повний код, українська, англійська й італійська сторінки та 42 автоматичні тести. Для зміни перекладів: python3 i18n-build.py (потрібен лише при редагуванні локалізації, не для розгортання).
